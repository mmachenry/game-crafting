# game-crafting
Files for printing game components.

# Useful tools

To convert a typical print and play PDF to PNGs to better work with image
manipulation scripts like most script I've written here in this repository
you can install ImageMagick and use convert. A multi-page PDF will be
converted to multiple PNG files with a number appended to the name that you
give as the second argument.

    convert Some_Game_PNP.pdf some_game.png

Higher resolution and converts the entire file automatically but to ppm

    pdftoppm Some_Game_PNP.pdf some_game
